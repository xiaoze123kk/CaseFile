# Agent Skill 分层与缓存工程验收

日期：2026-09-16。当前默认 Skill 发布：`agent-skill-runtime-v1`。

## 交付结果

- 39 个当前 Registry Agent 全部绑定不可变 Skill 发布。旧版单体提示词拆为角色和方法资源，Prompt Package 继续由运行时按组件选择；简单单段 Agent 保持 role-only。
- 发布加载会校验 Registry、Prompt 版本、资源哈希、组件顺序和工具策略。39 个当前提示词与迁移前逐字节一致，历史 Prompt 版本不会被自动绑定。
- 小说方案推荐从模块常量迁入 Prompt Repository，纳入版本、Skill 和调用审计。
- DeepSeek Chat Completions、严格 Tool、流式响应和 Agent SDK 请求统一经过物理调用审计；每次 SDK 重试独立记录。日志保存请求指纹、稳定前缀、工具和输出契约哈希、模型、延迟及原始 usage，不保存凭证或输入正文。
- usage 同时兼容 Chat Completions 与 Responses 字段，区分缺失、真实零值和异常缓存计数。
- 预算入口默认零网络，真实模式串行执行并在物理请求前落盘预留。未知用量保留预留，余额不足不发请求，同一账本不能覆写或自动续跑。

固定模型为 `deepseek-flash`，价格于 2026-09-16 按 DeepSeek 官方人民币高峰价重新核对。覆盖 Brief、Brief-to-Draft、Chat、规划、Judge、小说流式协作和上下文 Tool 七类代表路径；每类旧路径、新发布各运行两次，共 28 个逻辑及物理调用。

候选与基线的稳定前缀完全相同，所以候选观测可能复用基线阶段建立的供应商缓存。结果证明工程迁移没有破坏缓存，不证明迁移额外创造了 75% 的收益。短提示词路径命中较低；本次没有复制材料或填充提示词来追求更高比例。

此前三次真实运行的估算费用为 0.927561720 元，保守预算扣减为 1.85512344 元。本次完成后，估算费用累计 0.949621560 元，保守预算累计扣减 1.87718328 元，20 元预算剩余 18.12281672 元。

原始结果位于 `backend/var/benchmark/agent-engineering/live-smoke-20260916/`，包含冻结清单、逐物理请求账本和按首次/重复、Agent 分组的报告。本次是工程及成本冒烟，不是文学质量资格评测。
