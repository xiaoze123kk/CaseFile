日期：2026-09-05。**Pro 提高了本批候选的采用率与位置一致性，但仍未达到冻结门槛，不改变活动 v2 或 B3 资格结论。**

## 实验范围

来源为 `b3-diagnostic-v1-20260905-a` 已完成公开诊断中的72份润色稿（24场×3次生成）。原稿、润色稿、findings、Preservation 和既有 Flash 评审均不修改、不重新生成。

仅将 Pairwise 从 `deepseek-v4-flash` 改为 `deepseek-v4-pro`；Prompt、匿名正文、Profile、Schema、双位置调用顺序与采用规则不变。调用前对全部72例校验原稿绑定、完整Council策略及报告哈希、直接润色lineage、旧Flash决定，并用零网络请求构建验证新旧匿名输入一致。复评仍是公开开发诊断，不能替代新私有 B3。

## 结果

| 指标 | 第1轮 Flash → Pro | 第2轮 Flash → Pro | 第3轮 Flash → Pro |
|---|---|---|---|
| 稳定采用 | 8/24 → 16/24 | 8/24 → 14/24 | 9/24 → 15/24 |
| 整体位置一致 | 10/24 → 17/24 | 10/24 → 15/24 | 10/24 → 16/24 |

- 总采用：25/72（34.7%）→45/72（62.5%），增加20份，约27.8个百分点。
- 原来拒绝、Pro采用：21份；原来采用、Pro拒绝：1份；两者均采用：24份。
- 剩余27份Pro未采用：24份 `quality_unstable`、3份 `quality_rollback`。
- 两位置结果相同可以是 `tie`，不能把位置一致数等同于采用数。采用仍要求整体两次都偏好润色稿，且任一维度都不偏好原稿。
- 本次没有新运行语义Council；沿用原始已通过且精确绑定的72份Preservation证据，复用不能计作新的72次保真成功。

采用率提高说明换模型会明显影响筛选结果；这些候选没有独立人工质量Gold，不能把新增21份采用都称为已证实的“纠正误拒”。三轮仍均低于≥18/24采用门槛；此前Pro在公开偏好对上的镜像19/24也仍低于≥23/24，因此不晋级默认模型、不创建新私有包、不启动B4。
