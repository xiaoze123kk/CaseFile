## 冻结边界

- Quality findings 只在精确绑定的 Semantic Consensus `pass` 后运行。
- 固定五维：`pov_voice_consistency`、`scene_specificity`、`dialogue_narration_naturalness`、`dramatic_progression_pacing`、`readability_editability`。
- finding 必须引用服务端 Evidence 目录，不包含改写正文，也不能覆盖 Semantic verdict。
- Pairwise 使用 `deepseek-v4-flash`，同一原稿/润色稿以 `A=original/B=polished` 和反向位置各调用一次。
- Provider 只看到匿名 A/B 正文和 Profile prose 约束，不看到 original/polished、stage、round、selection reason、Prompt version 或来源 hash。
- 只有两次整体 preference 都映射为 polished，且任一维度在任一次都不映射为 original，才产生 `polished_accepted`；其他结果为 `quality_rollback` 或 `quality_unstable`。
- Pairwise 前必须证明 polished 直接来自 original 且 Preservation Consensus 完整通过；无效上游在 Provider 前失败关闭。
