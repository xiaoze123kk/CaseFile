# API 密钥管理

## 已确认决策

- 密钥显隐只作用于用户当前输入的新密钥；已保存的 AES-256-GCM 密文不会解密回传浏览器。
- 每个用户、每个 Provider 仍只有一条设置。设置页通过供应商切换完成查看掩码、替换模型/密钥和删除密钥。
- 删除密钥采用墓碑状态：清空密文、nonce、密钥版本和末四位，保留 Provider/模型配置行及历史 TaskRun 外键。
- queued、running 或 cancelling TaskRun 仍引用凭据时拒绝删除；任务结束后允许擦除。
- 同一 Provider 重新保存密钥时复用墓碑行、推进配置版本并恢复未验证状态。

## 明确排除

- 不提供已保存密钥的明文回显接口。
- 不自动取消或删除正在执行的 TaskRun。
- 不扩展为多把同 Provider 密钥、团队共享密钥或云端密钥托管。
