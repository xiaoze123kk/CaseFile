# 建案中心独立前端原型

日期：2026-08-05

## 已确认决策

- 原型使用独立路由 `/demo/intake`，不修改真实 `/` 建案工作流。
- 功能口径对齐当前真实 A 路径：最初想法、三档 Agent 润色校样、最多两道关键追问、人工降级、创作简报字段、约束抽屉、候选历史、对话修改与采用门禁。
- 原型只使用组件内 Fixture 状态，不请求真实 API、不导入 Workflow Store、不写 LocalStorage，也不向 `/demo` 工作台传递样例事实。
- 视觉采用“法证光台”方向：冷白矿物底、钴蓝操作信号、珊瑚提示色、技术字体与实时简报映射；不复用真实模式的数字档案纸样式。

## 本次范围

- 新增 `/demo/intake` 路由、原型组件、局部 CSS Module 与本地纯模型。
- 为演示壳增加建案原型类型标记，并解除该路由的正式模式桌面最小宽度。
- 增加主流程和隔离边界测试，同步 `AGENT.md` 职责地图。
- 完成桌面与移动浏览器视觉、交互和控制台检查。

## 明确排除

- 不接入后端 Brief Intake、Provider、TaskRun、SSE 或数据库。
- 不修改真实建案中心的业务组件、视觉或契约。
- B、C、D 三条入口仍保持后续开放状态，不在原型中伪造未实现流程。
- “查看工作台原型”只做页面预览跳转，不表示真实数据交接已经实现。

## 后续事项

- 若原型视觉获批，再单独决定哪些布局与组件迁入真实建案中心；迁移时必须继续使用服务端事实和真实完成门禁。
