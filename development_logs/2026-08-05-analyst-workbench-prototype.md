# 分析师工作台演示原型替换

## 已确认决策

- 本轮只替换 `/demo` 演示模式，不修改 `/`、`/brief`、`/workbench` 的正式 Workflow、真实 API 或数据库状态。
- 旧的建案、Brief、工作台、推理实验室、质量中心分页面原型退出；演示模式改为单一“分析师工作台”，旧演示子路径统一返回新工作台。
- 页面围绕一个可完整演示的主路径：选择事件 → 联动查看人物与证据 → 定位 S0/S1 问题 → 查看证据与知识状态对照 → 请求或审阅补丁 → 人工批准 → 局部重算/重新验证。
- 信息架构固定为顶栏、左侧对象导航、中央多视图主画布、右侧检查器、底部来源抽屉；演示数据继续与真实 Workflow/API 隔离。
- 视觉记忆点为贯穿对象、事件、问题、来源和审批状态的“证据脊线”；其他装饰保持克制，优先保证高频编辑、验证和审批可读性。
- 评审版配色改为“石墨黑 + 档案纸白 + 氧化铜”：`#171A1D` / `#202427` 承担深色框架，`#F3F1EB` / `#FBFAF6` 承担内容画布，`#C78B3C` 只承担当前操作、焦点与证据脊线，默认关系线使用中性灰 `#8E9694`；绿色 `#35A46F` 只表示通过或已解决，警告使用琥珀色，S0/S1 与阻断问题使用珊瑚红 `#D95C59`。
- “正式模式”入口使用低饱和铜色描边；选中菜单只保留铜色细线和浅底，不再出现整块高饱和品牌色。

## 竞品参考与转化

- [Palantir Gotham](https://www.palantir.com/platforms/gotham/)：采用近黑、白和低彩度框架的克制方法；转化为石墨顶栏和侧栏，让品牌色退出大面积结构区。
- [Maltego Graph](https://www.maltego.com/graph/)：参考深色桌面框架、白色关系画布和暖色操作提示；只吸收暖色工具感，不复制传统 Windows 工具外观。
- [i2 Analyst’s Notebook](https://i2group.com/solutions/i2-analysts-notebook) 与 [DataWalk](https://datawalk.com/product/)：参考“框架色、关系色、实体分类色”分离；默认连线改为灰色，人物、证据、事件、地点与假设各自拥有低饱和分类色。
- [Heptabase](https://heptabase.com/)：参考中性内容面和由内容承担颜色的方式；主画布改用暖灰档案纸，彩色只进入对象分类和语义状态。
- [Linkurious](https://linkurious.com/decision-intelligence-platform-graph-visualization/)：保留其白底图谱的清晰度，但刻意不沿用亮蓝企业 SaaS 主色。
- [Campfire](https://www.campfirewriting.com/)：参考暖色为叙事工具建立性格的思路；氧化铜只用于交互和卷宗索引，不把页面做成大面积橙棕色。

- 不接入真实 CaseFile、TaskRun、Agent Provider、音频文件、地图服务或导出器。
- 不把演示补丁写入 Canon，不改正式创作模式的数据模型、契约或后端接口。
- 不在本轮实现拖拽布局；所有可定位操作提供单击和键盘入口。
